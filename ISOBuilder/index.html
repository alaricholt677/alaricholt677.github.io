Level 2 · The idea

Meet the one-file desktop

Trusten is a self-managing Windows-like desktop packed into one native C++ executable. WinPE supplies the kernel, boot process, drivers, CMD, storage and Win32 environment. Trusten supplies the shell, windows, applications, accounts, settings and diagnostics.

One executable was not a limitation. It was the solution. It avoided scattering the environment across difficult DLL and directory deployments.
Concept unlocked.

Level 6 · Compiler

Forge Python and C++

Easiest MinGW-w64 method: install MSYS2, open MSYS2 UCRT64 from the Start menu, then install the 64-bit GCC toolchain with the command below.
Download MSYS2 installerOfficial MinGW-w64 MSYS2 guide
pacman -S mingw-w64-ucrt-x86_64-gcc

After installation, add C:\msys64\ucrt64\bin to Windows PATH if you want the normal builder process to find g++.exe outside the MSYS2 UCRT64 terminal.
