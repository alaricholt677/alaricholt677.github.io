Experimental software: use it in a virtual machine or test environment. WinPE is intended for deployment and recovery scenarios, so this shell has limitations compared with a full operating system.

Included experience

  • Full Win32 graphical shell
  • Desktop, draggable windows and taskbar
  • Browser and download workflow
  • File explorer, terminal and Notepad
  • Theme system and power menu

Recommended environment

  • VMware Workstation or VirtualBox
  • At least 1 GB of RAM
  • Networking configured by the virtual machine
  • Do not use as a replacement for Windows
